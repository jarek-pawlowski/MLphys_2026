# MLphys — Machine Learning in Physics

Course materials for **Machine Learning in Physics, Fall 2026**.

Course website: https://jarek-pawlowski.github.io/MLphys/

## Repository structure

- `index.md` — main course page
- `lectures/` — lecture index and links
- `labs/` — laboratory instructions and notebooks
- `seminars/` — seminar topics
- `assets/` — optional images and CSS

Each laboratory uses the same structure:

1. Goals
2. Preparation
3. Environment
4. Exercises
5. Questions
6. Optional tasks
7. Notebook

## Local preview

The website is built with GitHub Pages/Jekyll. For ordinary content updates, Markdown files can be edited directly on GitHub.
