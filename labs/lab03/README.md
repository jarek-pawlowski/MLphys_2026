# Lab 3 — Group-Equivariant CNNs

## Goals

After completing this laboratory you should be able to:

- explain the connection between physical symmetries, group actions, and equivariance;
- distinguish equivariance from invariance;
- test the response of convolutional layers to translations and rotations;
- understand and implement lifting and group convolutions for the rotation group $C_4$;
- compare the accuracy and parameter efficiency of standard and $C_4$-equivariant CNNs.

## 3. Experiments

We investigate how convolutional layers respond to symmetry transformations. The notebook introduces the $C_4$ group of rotations by $0^\circ$, $90^\circ$, $180^\circ$, and $270^\circ$ and implements two layers:

- **LiftingConv2d**, mapping a 2D image to feature maps with an additional rotation-group axis;
- **GroupConv2d**, performing convolution on feature maps defined over spatial coordinates and $C_4$.

We then use these layers to construct a $C_4$-equivariant CNN and compare it with a standard CNN on images generated from hydrogen-atom wavefunctions.

## 4. Tasks

1. **Translation equivariance.** Demonstrate that a convolutional layer is equivariant to translations using your own images. Discuss whether this property is preserved when several layers are stacked into a CNN.
2. **Rotation equivariance.** Test whether an ordinary convolutional layer is equivariant to $90^\circ$ rotations. Examine how a rotationally symmetric filter changes the result.
3. **Group convolution.** Inspect the filters generated by `LiftingConv2d` and `GroupConv2d`. Explain how a rotation acts on the spatial coordinates and cyclically permutes the $C_4$ group axis (`rotate(x, 1).roll(1, dims=-3)`).
4. **Equivariance test.** Verify the equivariance of `GroupConv2d` on your own input. Construct the correctly transformed output and compare it with the layer output for a transformed input.
5. **Final task — hydrogen-orbital classification.** Classify the principal quantum number $n$ from 2D images of hydrogen-atom wavefunctions, comparing a standard CNN with a $C_4$-equivariant CNN:
   - Generate **1000/500/500 training/validation/test** images for the three classes $n=2,3,4$. Randomize the allowed quantum numbers $l,m$, the spatial scale parameter $a_0$, and the image orientation (rotations by multiples of $90^\circ$).
   - Train both models on the same data using comparable training procedures. Use the `C4CNN` architecture provided in the notebook as a starting point.
   - Vary the channel widths to obtain models with comparable **numbers of trainable parameters**.
   - Plot **test accuracy versus the number of trainable parameters**. Which architecture is more parameter-efficient?

## 5. Questions

- Why is an ordinary convolution equivariant to translations but not, in general, to rotations?
- What is the role of the additional group axis in lifting and group convolutions?
- How does the group action on $X \times C_4$ differ from rotating an ordinary image?
- Why might a $C_4$-equivariant network need fewer trainable parameters to achieve a given classification accuracy?
